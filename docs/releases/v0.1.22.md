### 新增功能

- 新增 Linux 版本：出 AppImage，文件管理走 XDG 目录（`$XDG_CONFIG_HOME/DSH`、`xdg-open`、zenity/kdialog），登录自启写 `~/.config/autostart`。
- 官网落地页和 README 补上 Linux 下载入口。
- 同时出 deb 包（`DSH-X-<版本>-amd64.deb`）：装进 `/opt/DSH-X`、带菜单项、能用 `apt remove dsh-x` 卸干净。deb 版不支持外壳自更新，换外壳要到发布页下新包；核心照常自动更新。

### 问题修复

- 修复更新正在运行的实例后，首页一直卡在「正在安装」。

### 其他变更

- 重新构建旧版兼容安装包 `DSH-Setup.exe`，0.1.18 及更早的更新器仍能升级。

## English

### New Features

- Add a Linux build: AppImage output; file management uses XDG directories (`$XDG_CONFIG_HOME/DSH`, `xdg-open`, zenity/kdialog) and autostart is written to `~/.config/autostart`.
- The landing page and README now link the Linux download.
- A deb package (`DSH-X-<version>-amd64.deb`) is published as well: it installs to `/opt/DSH-X`, adds a menu entry and uninstalls with `apt remove dsh-x`. The deb build cannot self-update the shell — grab the new installer from the releases page — while core updates still come from npm.

### Bug Fixes

- Fix the home page staying on "Installing" after updating a running instance.

### Chores

- Rebuild the legacy `DSH-Setup.exe` bridge so updaters from 0.1.18 and earlier can still upgrade.
