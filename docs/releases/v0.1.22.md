## English

### New Features

- Add a Linux build: AppImage output; file management uses XDG directories (`$XDG_CONFIG_HOME/DSH`, `xdg-open`, zenity/kdialog) and autostart is written to `~/.config/autostart`.
- The landing page and README now link the Linux download.

### Bug Fixes

- Fix the home page staying on "Installing" after updating a running instance.

### Chores

- Rebuild the legacy `DSH-Setup.exe` bridge so updaters from 0.1.18 and earlier can still upgrade.
